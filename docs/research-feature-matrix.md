([protocols doc](https://learning.postman.com/latest-v-12/docs/use/send-requests/protocols/protocols.md))\n- **Scripting:** `pm.*` JS sandbox (pre-request/post-response, tests, `pm.datasets()`, `pm.vault`), package library (Enterprise governance over packages).\n- **Collection runner & data files:** CSV/JSON iteration data, datasets (queried/joined views), scheduled cloud runs.\n- **Postman CLI vs Newman:** Postman CLI (`postman login/init`, `collection run`, `spec lint` governance, `workspace push/sync`, plus mocks/monitors/perf/flows/webhooks/SDK-gen/AI commands, `--json` for CI/agents, results reported to cloud). Newman remains the open-source MIT runner but gets no governance/vault/cloud reporting. ([CLI overview](https://learning.postman.com/docs/postman-cli/postman-cli-overview/))\n- **Flows / AI Agent Builder:** visual canvas with AI Agent / AI Request / Create-with-AI blocks; deployable as webhooks; Agent Mode (Mar 2026) drives specs/tests/mocks via MCP; one-click API→MCP server (\"AI Tool Builder\"), MCP server network, Claude Code plugin + Cowork skill (Mar 2026). ([Agent Builder](https://www.businesswire.com/news/home/20250122392157/en/), [Agent Mode](https://techintelpro.com/news/ai/agentic-ai/postman-launches-ai-native-api-development-with-agent-mode))\n- **Governance (Enterprise):** Spec Hub/API Builder, deployment control, API & package library governance, account discovery & control, external workspace archival.\n- **No self-hosted/on-prem option**; EU-only data residency is Enterprise-only.\n\n## 2.
