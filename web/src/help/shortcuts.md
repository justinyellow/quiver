# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+K` | Search requests, collections and environments, or run a command |
| `Ctrl+N` | New request tab |
| `Ctrl+Enter` | Send the request, or send a WebSocket message |
| `Ctrl+S` | Save the current request, collection, folder or environment |
| `Ctrl+W` | Close the current tab |
| `F1` | Open help for the current screen |
| `{{` in a URL or body | Variable autocomplete |
| Middle-click a tab | Close it |
| Right-click a tab | Close all other tabs |
| `Esc` | Close a dialog |

On macOS, use `Cmd` in place of `Ctrl`.
