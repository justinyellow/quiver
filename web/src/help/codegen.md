# Code generation

Turn any request into ready-to-paste code.

1. Open a request and click **Code** in its header.
2. Choose a target. Quiver remembers your choice.
3. Click **Copy**.

If you have sent the request, the code uses the real values that were sent, with variables resolved and auth applied. Before the first send, `{{variables}}` appear as written.

## Targets

cURL (bash and Windows cmd), raw HTTP, JavaScript fetch, Axios, Node fetch, Node `https`, Python requests, Python `http.client`, Go, Java OkHttp, Java HttpClient, C# HttpClient, C# RestSharp, PHP cURL, PHP Guzzle, Ruby, Rust reqwest, Swift URLSession, Kotlin OkHttp, PowerShell, Dart, wget and HTTPie.

The same languages are available in the **Code samples** picker in [documentation](#topic:docs).
